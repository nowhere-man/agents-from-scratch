# 时序建模、推理与长视频

> [!important] 一句话核心
> 视频理解的难点不仅是识别一帧里有什么，更是通过时序建模知道什么在何时发生、持续多久、顺序如何及是否被漏采样；长视频系统的首要工作是管理观察预算和证据，而非盲目增加帧数。

## 静态识别与时序理解的差别

| 问题 | 需要什么证据 | 常见失败 |
|---|---|---|
| “画面里有安全帽吗？” | 一帧清晰画面 | 小目标、遮挡、分辨率不足 |
| “谁先离开房间？” | 人物身份跨帧关联 + 顺序 | 采样跳过离开瞬间、人物混淆 |
| “发生了几次碰撞？” | 完整事件边界 + 去重 | 快速动作漏采样，同一事件多次计数 |
| “告警在什么时候开始？” | 时间坐标 + 对应视听证据 | 时间戳漂移、音画不同步、只看关键帧 |
| “为何发生事故？” | 多段证据和因果推断 | 相关性被误说成因果，关键离屏因素不可见 |

因此，视觉问答成功不等于视频 Agent 能可靠做事件检测、定位、计数或因果归因。

## 采样决定上限

视频长度与帧率使全量逐帧输入很昂贵。系统通常需要采样和压缩：均匀抽帧、镜头切分、运动/变化检测、查询引导的自适应采样，或先用轻量模型选候选片段。

| 策略 | 适用情况 | 风险 | 补救 |
|---|---|---|---|
| 均匀抽帧 | 全局概览、慢变化场景 | 短事件、开始/结束时刻被跳过 | 发现候选后局部加密采样 |
| 镜头切分 | 剪辑视频、场景概述 | 同一镜头内快速事件仍会漏 | 结合运动或任务信号 |
| 变化/运动触发 | 异常、动作、事件候选 | 静态但重要的文字/物体可漏 | 同时保留低频全局采样 |
| 查询引导采样 | 有明确目标对象/事件 | 初始检索错会导致后续全错 | 保留覆盖性样本和不确定性回退 |
| 全量/高密度 | 短视频、监管取证、关键片段复核 | 成本、延迟、token 爆炸 | 只用于小范围，记录预算 |

> [!warning] 未被观察到，不等于未发生
> 输出必须区分状态及原因：`not_observed` 表示采样、可见区域或模态覆盖不足；`insufficient_evidence` 表示已观察到候选，但证据不足以确认；只有任务契约要求的覆盖已经满足，才可返回 `confirmed_negative`。这三种状态都不能被一句“未发现”替代。

## 时间表示、压缩与长度外推

模型必须同时承载帧内空间信息和跨帧时间关系。常见设计会给帧/clip 加时间位置编码，合并相邻视觉 token，使用时间池化或选择少量代表帧。它们降低 token 数，却可能损失短暂动作、对象身份连续性和精确边界。

### 统一时间基准

视频 PTS、帧号、转码 FPS、ASR/OCR 时间戳和字幕时间轴可能并不一致，尤其在可变帧率、裁剪、拼接或转码后。系统应选定一个 canonical timeline，并保存从每种局部坐标到该时间轴的换算、版本和误差范围；不要仅凭“帧号 / 标称 FPS”生成可审计的事件时间。

长视频中，限制来自三个层面：

1. **输入覆盖**：是否真正采到了需要的瞬间和模态。
2. **表示压缩**：采到的信息在 patch、token、池化和摘要中保留了多少。
3. **推理与定位**：模型能否把相关片段与问题、时间戳、对象和事件边界正确关联。

即使产品宣称支持较长视频，也要以你的事件持续时间、可接受时间误差和视频类型测试以上三层。

## 一个可审计的长视频查询流程

定义事件、时间精度、状态语义和证据要求 → 全局低密度覆盖与索引 → 候选镜头/片段检索 → 局部高密度帧、音频、OCR 复核 → 多模态模型做语义判断 → 若证据充分则返回时间范围、来源和不确定性；若覆盖不足返回 `not_observed`，若候选证据不足返回 `insufficient_evidence`，再按风险请求补充或人工复核。

该流程的关键不是一定要多次模型调用，而是让任何“发生于何时”的结论都能回到原始片段验证。

## 计数、定位与因果的额外边界

- **计数**：先定义单位（人、独立对象、进入次数、事件次数）、去重规则、遮挡行为和时间窗口；必要时用检测/跟踪或规则聚合，不让 LLM 从摘要文本中猜数。
- **定位**：输出应区分帧号、视频时间、片段 ID 和近似程度；输入/转码 FPS 的差异会影响换算。
- **身份连续性**：跨镜头、遮挡、相似外观和镜面反射会导致对象身份断裂；不能只凭模型一句“同一个人”。
- **因果**：视频通常只提供观测相关性。除非任务规则和证据支持，使用“发生在……之后”“画面显示……”而非“因为……所以……”。

## 最小 eval 设计

测试集应按事件持续时间、镜头风格、光照、对象密度、音画线索、字幕质量和视频长度分层。指标至少分开记录：事件召回/误报、时间定位误差与时间轴漂移、计数误差、证据可回查率、`not_observed` / `insufficient_evidence` / `confirmed_negative` 的正确使用率、成本与端到端延迟。
